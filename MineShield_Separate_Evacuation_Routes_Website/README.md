# MineShield — Separate Evacuation Route Demonstration

Open `index.html` in Chrome or Edge. Frontend-only simulation.

## What changed
- H-01 uses the **west portal** demonstration route.
- H-03 uses a **separate east egress** demonstration route; H-02 also uses east egress when its own upper-level alert is triggered.
- Routes and endpoints appear as distinct colored dashed paths on the 3D map. Click each helmet for its assigned exit and progress.
- Fall alerts still freeze the affected helmet marker at the last-known simulated position.
- Same-level gas alerts still warn all helmets assigned to that level.
- The drill/rescue notification workflows and other pages remain.

## SAFETY
These routes are fictional demonstration paths. The east egress is an illustrative alternative, **not a verified or constructed mine exit**. No real gas sensor, ventilation map, surveyed mine path, positioning system, safe-route algorithm or rescue system is connected. Ascending toward the surface does not necessarily mean gas levels are safer. In a real mine, follow approved evacuation plans and instructions based on validated gas/ventilation conditions; never use this prototype for actual navigation.
