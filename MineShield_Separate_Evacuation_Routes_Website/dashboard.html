Architecture reflected from PPT

1
Wearable node

ESP32 + MQ prototype gas sensors + MPU-6050 + haptic/buzzer.

2
Fixed anchor

Receives ESP-NOW messages and tags a last-seen region using RSSI.

3
Surface gateway

Bridge to the Flask API, packet log and command dashboard.

Important implementation notes

Safety measurements

MQ response must not be described as certified gas concentration. Add and calibrate a suitable O₂ sensor before reporting actual O₂.

Location wording

Show “last-seen anchor zone,” never exact GPS-style miner coordinates.

Deployment status

Intrinsically safe packaging, certified sensors and mine trials are future work in the provided slides.
